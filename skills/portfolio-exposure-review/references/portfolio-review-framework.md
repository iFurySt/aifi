# Portfolio Review Framework

Use this reference when a research idea must be evaluated in portfolio context.
The output should explain fit, constraints, and monitoring needs without
crossing into autonomous trading.

## Review Modes

| Mode | Use when | Main question |
| --- | --- | --- |
| New idea fit | Target is not in the portfolio | What exposure would this add? |
| Existing holding review | Target is already owned | Has the position's role or risk changed? |
| Add or trim framing | User asks about sizing direction | What evidence would justify more or less exposure? |
| Watchlist review | Idea is not actionable yet | What trigger would make it worth revisiting? |
| Portfolio risk pass | Multiple holdings share risk | Where are hidden concentrations or duplicate bets? |

## Inputs To Request Or Label Missing

- current position size, cost basis, unrealized gain or loss, and holding period
- portfolio NAV, sector weights, top positions, cash, leverage, and benchmark
- mandate constraints, time horizon, liquidity needs, tax considerations, and
  restricted securities
- target liquidity, average volume, volatility, beta, drawdown history, and
  options or short-interest signals
- thesis confidence, valuation range, risk register, and catalyst timeline

## Exposure Dimensions

Review only the dimensions that matter for the supplied portfolio context:

- issuer and single-name concentration
- sector, industry, theme, and supply-chain overlap
- geography, currency, rates, commodity, and macro exposure
- factor exposure such as growth, value, quality, momentum, size, duration, or
  leverage
- customer, supplier, platform, or regulatory dependency
- event and catalyst overlap across names
- liquidity and exit capacity

## Sizing Discipline

- A high-conviction thesis can still be a poor fit if it duplicates an existing
  portfolio risk.
- A cheap valuation can still require small sizing if liquidity, leverage,
  binary risk, or drawdown contribution is severe.
- Avoid precise position-size recommendations unless the portfolio inputs,
  mandate, and risk budget are explicit.
- When portfolio data is missing, frame the analysis as questions and
  constraints rather than allocation advice.
- Use ranges and qualitative concern levels when inputs are incomplete.

## Watch Triggers

Examples of portfolio-level triggers:

- position weight breaches a user-defined concentration limit
- sector or theme exposure rises above mandate or comfort range
- valuation upside narrows while risk remains unchanged
- risk diligence escalates a thesis-breaking issue
- liquidity declines or volatility regime changes
- catalyst timing changes and several holdings depend on the same event
