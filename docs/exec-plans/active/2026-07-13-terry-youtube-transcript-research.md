# Terry YouTube Transcript Research

## Goal

Build a reusable raw-data archive for Terry Chen's public YouTube channel, then use it to analyze his historical portfolio, wealth and investing development, and practical investment-learning patterns that can be generalized for ordinary investors.

## Scope

- In scope: collect all public video links from `https://www.youtube.com/@hackbearterry`, extract available transcript text through YouTube-visible transcripts and online link-to-transcript providers, preserve source metadata, and create repo-local artifacts for later portfolio and learning-plan analysis.
- In scope: clearly separate raw transcripts from synthesized investment analysis.
- Out of scope for the first collection slice: downloading video/audio files as the primary path, storing private account data, or presenting generated research as regulated financial advice.

## Context

- Relevant docs: `docs/REPO_COLLAB_GUIDE.md`, `docs/ARCHITECTURE.md`, `docs/design-docs/core-beliefs.md`, `docs/SECURITY.md`.
- Relevant skill: `skills/research-evidence-archive/SKILL.md`.
- Relevant paths: `research/targets/terry-chen-youtube/`, `scripts/collect_youtube_transcripts_obu.py`.
- Constraint: direct `yt-dlp --list-subs` on individual videos hit YouTube bot checks, so transcript extraction uses the user's connected Chrome session through Open Browser Use and reads the visible transcript panel rather than exporting browser cookies.
- Constraint: direct no-cookie `yt-dlp` audio download for an individual video also hit YouTube bot checks. The active main path is online link-to-transcript providers, not video download / ASR.

## Risks

- Risk: YouTube UI or transcript DOM changes can break extraction.
- Mitigation: keep the extractor small, resumable, and preserve per-video failure states in `manifest.json`.
- Risk: Some videos may not expose transcript panels.
- Mitigation: record missing transcripts explicitly and reserve fallback ASR or alternate transcript sources for a later slice.
- Risk: Raw transcript text can be noisy or copyrighted source material.
- Mitigation: store it as raw evidence with source URLs and use summaries/citations in synthesized artifacts rather than long quotes.

## Milestones

1. Create channel inventory and transcript extraction workflow.
2. Collect as many transcript files as YouTube exposes through the browser transcript panel.
3. Build an extraction layer for portfolio holdings, wealth timeline, cash-flow disclosures, and strategy mentions.
4. Synthesize practical portfolio and learning-plan artifacts with evidence links and uncertainty labels.
