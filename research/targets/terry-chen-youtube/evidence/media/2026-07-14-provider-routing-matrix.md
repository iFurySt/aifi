## Practical Next-Step Rule

Do not spend more time rerunning ordinary direct-caption providers against the same high-value fallback set. The useful next tests must satisfy one of these:

1. The provider accepts a YouTube URL and returns a job id or transcript without requiring local audio/video download. YouTLDR currently satisfies this for many hard cases.
2. It can be accessed in the user's browser with an authenticated session and exports transcript text.
3. It specifically changes state from a prior blocker, such as AI Video Summarizer quota reset/login, NoteGPT login state, or Transcriptly's `No audio stream found` error clearing.
